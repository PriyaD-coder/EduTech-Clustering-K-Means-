# Task 10: Clustering using K-Means

## Overview
This project demonstrates clustering using the K-Means algorithm.

## Objectives
- Understand clustering (unsupervised learning)
- Implement K-Means algorithm
- Use Elbow method to find optimal K
- Visualize clusters and centroids

## Tools Used
- Python
- Scikit-learn
- Pandas
- Matplotlib

## Dataset
- Mall Customers Dataset

## Steps
1. Import libraries
2. Load dataset
3. Select features (Income, Spending Score)
4. Apply Elbow Method
5. Train K-Means model
6. Visualize clusters

## Key Concepts
- Centroids: Center of clusters
- Inertia: Sum of squared distances
- Elbow Method: Technique to choose K
